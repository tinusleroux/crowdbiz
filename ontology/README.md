# Ontology

The locked MVP object model, graph shape, and claim contract live in
[CONTRACT.md](CONTRACT.md).

The vocabularies are authored, versioned YAML. They are data rather than graph
nodes, and function and seniority never appear on source claims. Matching is not
part of the ontology.
