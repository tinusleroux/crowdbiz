# Ontology

The locked MVP object model, graph shape, and claim contract live in
[CONTRACT.md](CONTRACT.md).

The vocabularies are authored, versioned YAML. They are data rather than graph
nodes, and function and seniority never appear on source claims. Matching is not
part of the ontology. How matching improves — seed, human-validate unknowns,
then promote repeated decisions to rules — is [LEARNING.md](LEARNING.md).

| File | Role |
| --- | --- |
| [CONTRACT.md](CONTRACT.md) | Locked MVP object, graph, and claim contract |
| [LEARNING.md](LEARNING.md) | Agreed loop: seed with rules, validate unknowns, inform rules |
| [functions.v2.yaml](functions.v2.yaml) | Accepted function vocabulary (`version: 2`; supersedes v1) |
| [seniority.v1.yaml](seniority.v1.yaml) | Accepted seniority vocabulary (`version: 1`) |
| [functions.v1.yaml](functions.v1.yaml) | Superseded; do not use for interpretation |
